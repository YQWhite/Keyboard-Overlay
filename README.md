# Keyboard-Overlay

一款轻量级、高度可定制的实时按键显示工具，专为直播、教程录制及电竞需求打造。项目采用现代极简的专业电竞视觉设计风格，摒弃了繁杂的极客感，为观众提供最清晰、纯粹的按键反馈体验。

## ✨ 亮点功能

*   **现代极简美学**：电竞级专业视觉设计，界面干净利落。
*   **桌面透明覆盖**：支持鼠标穿透的全局透明悬浮层，不影响任何系统日常操作。
*   **高级定制控制台**：内置 Web 后台，支持可视化调整按键布局、颜色、拖影方向及自动显隐动画。
*   **OBS 完美兼容**：内置独立本地 HTTP 服务，一键复制链接即可作为 OBS 浏览器源使用。
*   **便携式单文件**：打包为轻量的单 EXE 文件，配置文件原地持久化，配置永不丢失。

## 🚀 运行方式

无需复杂的安装与环境配置，真正的开箱即用：

1. 将打包好的 `KeyboardOverlay.exe` 放置在任意文件夹中。
2. **直接双击 `KeyboardOverlay.exe`** 即可启动。

> **提示**：程序首次运行时，会自动在 EXE 同级目录下释放 `config.json` 和 `stats.json`，用于持久化保存你的自定义布局和按键统计数据。

## 📦 如何打包

如果你修改了项目源码并希望自行构建单文件 EXE，请按以下步骤操作：

1. **安装环境依赖**：
   确保你的电脑已安装 Python，并在终端执行以下命令安装所需模块：
   ```bash
   pip install PySide6 websockets keyboard pyinstaller
   ```
2. **一键编译构建**：
   在项目根目录下，双击运行 `build.bat` 批处理脚本。
3. **获取成品**：
   打包完成后，新的 `.exe` 可执行文件将生成在根目录的 `dist` 文件夹中。

> **平台说明**：本项目依赖底层 API 实现全局键盘钩子 (Hook) 与特殊的 GUI 透明穿透属性，当前完美兼容 Windows 系统。
